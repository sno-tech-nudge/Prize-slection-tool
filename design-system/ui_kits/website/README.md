# the^delta — Website UI kit

Interactive recreation of the^delta marketing site, composed from the design-system components.

## Files
- `index.html` — mounts the app; simple in-memory router (home · programs · stories · apply).
- `Site.jsx` — top nav + footer (`Nav`, `Footer`).
- `Home.jsx` — hero (AngularBanner), stats, three-program grid, testimonial, CTA strip.
- `Programs.jsx` — program listing with Tabs + rows.
- `Apply.jsx` — application form (Input / Select / Radio / Checkbox / Textarea / Toast).

## Run
Open `index.html`. It links `../../styles.css` and `../../_ds_bundle.js`, then loads the JSX screens.

## Notes
This is a cosmetic recreation, not production code. Copy is illustrative (the^delta is a the/nudge initiative supporting social entrepreneurs). Photography is rendered black & white per brand rules.
