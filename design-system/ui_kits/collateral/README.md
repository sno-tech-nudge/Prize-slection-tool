# the^delta — Collateral UI kit

Reusable creative templates matching the brand's marketing collateral (social posts, testimonials, program banners).

## Files
- `index.html` — gallery of the three templates.
- `Collateral.jsx` — `ImpactPost` (square social), `TestimonialCard` (square), `ProgramBanner` (wide).
- `image-slot.js` — drop-in photo placeholder (starter component).

## Usage
Text is live — edit directly. Photo areas are `<image-slot>`s: drop a **black-and-white** photograph in. The testimonial ships with a sample B&W portrait.

## Brand rules honoured
- Caret / wordmark placement (top-right on posts, top-centre on cards).
- Sharp edges everywhere; red diagonal cuts on the banner.
- Yellow reserved for the quotation mark only (≤10%).
- Argent-italic emphasis words ("impact") and CTAs ("apply now").
- Photography in black & white.
