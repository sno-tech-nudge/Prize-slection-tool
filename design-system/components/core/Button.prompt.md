Square-edged action button; primary is delta red, labels usually lowercase.

```jsx
<Button>apply now</Button>
<Button variant="secondary">learn more</Button>
<Button variant="ghost">skip</Button>
<Button variant="cta">apply now</Button>   // uppercase, tracked — collateral CTA
```

Sizes: `sm | md | lg`. Supports `iconLeft` / `iconRight` and `disabled`.
