Signature hero banner framed by sharp red diagonal cuts — use for program headers and page heroes.

```jsx
<AngularBanner
  eyebrow="registration now open"
  title="the^delta incubator"
  subtitle="transform your ideas into impact."
  action={<Button variant="cta">apply now</Button>}
/>
```

`tone="ink"` for a charcoal canvas. Pass a B&W image via `media` to pin it bottom-right.
